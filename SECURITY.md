# Security

## Supported line

The current development line is `0.1.x`.

## Reporting

Use the repository's private security-reporting mechanism when available. Do not publish credentials, tokens, private repository contents, private account identifiers, hostnames, IP addresses, or other secrets in a public issue.

## Public-repository boundary

This repository is intentionally public. It must contain only reusable implementation, sanitized examples, tests, benchmarks, release artifacts, and explanatory documentation.

Private development state, provider installation identifiers, private account details, operational host data, and unreleased internal project material belong outside this repository.
